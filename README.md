NextJs store with Wix CMS

## Getting Started

To start working install all dependencies and configure .env:

```bash
npm run dev
```

.env expamle

NEXT_PUBLIC_WIX_CLIENT_ID="11111-1111-1111-1111-111111111111" your wix client ID
FEATURED_CATEGORY_ID="00000"

you can add your custom categories in .env

Local server on [http://localhost:3000](http://localhost:3000)
